# Biblioteca em Python

Sistema simples de biblioteca com duas classes: `Livro` e `Biblioteca`. Da pra
cadastrar livros, emprestar, devolver e listar o que esta disponivel no
momento.

## O que pratiquei

- Classes e objetos em Python
- Separar responsabilidade entre `Livro` (o dado) e `Biblioteca` (as regras)
- Lista de objetos e busca dentro dela
- Validacao simples nos metodos de emprestimo e devolucao
- Achar um bug testando o fluxo de verdade, nao só lendo o codigo

## Como rodar

```
python main.py
```

O `main.py` ja tem um cenario de teste: cadastra livros, empresta, tenta
emprestar de novo (e mostra o aviso) e devolve.
